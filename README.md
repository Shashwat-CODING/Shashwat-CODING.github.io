## 🚀 Featured Projects

### 🎵 **[Muzo — Premium YouTube Music Client](https://github.com/Shashwat-CODING/Muzo)**
A feature-rich, privacy-focused YouTube Music client built with Flutter. Premium ad-free experience with background playback, offline downloads, synchronized & karaoke lyrics, and gesture-driven controls.
- **Tech Stack**: Flutter, Dart, Riverpod, Just Audio, youtube_explode_dart
- **Highlights**: Glassmorphism UI, Lofi Mode, Gesture Player, Karaoke Lyrics, RapidAPI Fallback, Dynamic Theming
- **Status**: ⭐ Actively Maintained

### 🎧 **[ytify — Ethical YouTube Audio Streaming](https://github.com/Shashwat-CODING/ytify)**
A lean, modern, and intentional YouTube audio streaming platform built with SolidJS. High-performance streaming even on low-speed networks with comprehensive queue management, playlists, and PWA support.
- **Tech Stack**: TypeScript, SolidJS, Vite, Netlify Edge Functions, Invidious
- **Highlights**: Dynamic Theming, Radio Mode, Synced Lyrics, Personalized Recommendations, Audio Downloads, PWA
- **Status**: ⭐ Production Ready

### 🎼 **[Beatbump — Alternative YouTube Music Frontend](https://github.com/Shashwat-CODING/Beatbump)**
A privacy-focused alternative frontend for YouTube Music created using Svelte/SvelteKit and Golang backend. Features automix, no ads, background playback, and P2P data synchronization.
- **Tech Stack**: Svelte, SvelteKit, Go, WebRTC, IndexedDB
- **Highlights**: Automix, Local Playlist Management, Group Sessions (P2P), Custom YouTube API Wrapper, Offline Downloads
- **Status**: ⭐ Feature Complete

### 🛠️ **[innertube.js — YouTube API Library](https://github.com/Shashwat-CODING/innertube.js)**
A lightweight, powerful library for interacting with YouTube API using InnerTube protocol. Comprehensive YouTube & YouTube Music integration with full search, browse, and extraction capabilities.
- **Tech Stack**: JavaScript (Node.js), YouTube InnerTube API
- **Highlights**: Full YouTube API Access, YouTube Music Integration, Comments & Captions, Lyrics & Mood Playlists, Pagination Support, Error Handling
- **Status**: ⭐ Production Ready, NPM Package

### 🌐 **[Streamion — VPN-Capable Video Backend](https://github.com/Shashwat-CODING/streamion)**
A specialized Invidious-compatible backend designed for restricted network environments. Combines Go-based WireGuard proxy with Deno/TypeScript application in a single Docker container.
- **Tech Stack**: TypeScript, Deno, Go, WireGuard, Docker
- **Highlights**: VPN Routing, Multi-stage Docker Build, Health Checks, Zero Privileged Capabilities, Restricted Network Support
- **Status**: ⭐ Production Ready

### 📱 **[MCXNow — Live MCX Rates Mobile App](https://github.com/Shashwat-CODING/MCXNow)**
Real-time commodity exchange rates viewer with Flutter mobile app and Python backend API.
- **Tech Stack**: Flutter, Dart, Python, WebSocket
- **Highlights**: Real-time Updates, Live MCX Rates, Responsive Design
- **Status**: ⭐ Active

### 💾 **[Muzo Backend](https://github.com/Shashwat-CODING/muzo-backend)**
Backend API and services powering Muzo music streaming platform. Handles YouTube data fetching, music stream routing, and API management.
- **Tech Stack**: Node.js, Express, YouTube InnerTube
- **Highlights**: API Management, Music Stream Handling, YouTube Integration

### 🎬 **[Free Image Generation API](https://github.com/Shashwat-CODING/free-image-generation-api)**
Serverless image generation API powered by Cloudflare Workers with AI capabilities.
- **Tech Stack**: Cloudflare Workers, JavaScript
- **Highlights**: Serverless Architecture, Zero Infrastructure Overhead

### 🎯 **[Uma — Unified Instances Maintainer](https://github.com/Shashwat-CODING/Uma)**
Automated periodic maintainer for unified instances list. Keeps track of alternative frontends and their availability.
- **Tech Stack**: TypeScript, Node.js

### 🎥 **[ViewTube — Open Source Privacy YouTube](https://github.com/Shashwat-CODING/viewtube)**
